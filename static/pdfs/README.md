# Policy PDFs (`static/pdfs/`)

Drop policy PDFs here using these **exact** filenames (paths are hard-coded in `content/policies/*.md`):

| File | Policy page | Kind |
|------|-------------|------|
| `safeguarding.pdf` | `/policies/safeguarding-policy/` | Public statement |
| `health-and-safety.pdf` | `/policies/health-and-safety-policy/` | Public statement |
| `equality-and-diversity.pdf` | `/policies/equality-and-diversity-statement/` | Public statement |
| `anti-bullying.pdf` | `/policies/anti-bullying-policy/` | Full policy (bullying & harassment) |
| `complaints.pdf` | `/policies/complaints-procedure/` | Full policy |
| `safer-recruitment.pdf` | `/policies/safer-recruitment-policy/` | Full policy |

Statement pages set front matter `statement: true` so the layout shows that the full policy is available on request.

Do not rename without also updating front matter `pdf_src` on the matching policy page.
